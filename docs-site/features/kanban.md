# 智能看板

看板是 FlowMind 的协作中心：任务以卡片形式在自定义状态列间流转，支持拖拽、子任务、评论与实时通知。

![智能看板](/images/03-kanban.png)

## 核心能力

- **拖拽式任务卡片**：@dnd-kit 驱动，列间拖动即时落库
- **自定义状态列**：增删改状态列，按团队流程自由编排
- **任务要素齐全**：子任务拆分、优先级、截止日期、负责人、评论
- **评论 @ 提及**：被 @ 的成员实时收到通知
- **稳定任务编号**：任务卡片和详情展示项目内任务 ID，讨论时可以准确定位
- **跨任务引用**：在任务描述或评论中输入 `#` 搜索并引用同项目任务

## 任务引用

在任务描述或评论中输入 `#` 后继续输入任务编号或标题，即可从当前项目中选择目标任务。保存后引用会显示为可点击链接，直接打开对应任务详情。

- 引用关系双向可查：任务详情同时展示“引用了”和“被引用”
- 修改描述或评论时自动同步关系，删除原文后不会残留旧引用
- 删除任务或评论时自动清理关联记录
- 搜索和引用始终受项目权限约束，不会泄露其他项目的任务

## 列内筛选与排序

看板顶部工具栏提供纯前端过滤（任务已全量加载，零延迟）：

- **关键词筛选**：匹配标题与描述
- **负责人筛选**：按成员过滤
- **优先级筛选**：只看高优 / 中 / 低

每列内可独立排序：

- 按创建时间 / 更新时间 / 优先级 / 截止日期
- 升降序一键切换

::: tip
筛选条件保存在组件状态，刷新页面不保留——看板始终回到全局视图，避免"找不到任务"的困惑。
:::
