# 版本变化

FlowMind 当前正式版本为 `v0.2.2`。这一版本集中改善了工作流连贯性、界面一致性、报告生成可靠性和生产更新的恢复能力。

## v0.2.2

发布时间：2026 年 7 月

### 工作区与视觉系统

- 统一应用页面、项目对话框、任务对话框、知识库与助手面板的视觉语言。
- 引入沉浸式确认对话框，对删除、更新与回滚等高风险操作提供一致的确认路径。
- 重构知识库、通知、项目成员、报告、个人资料与系统管理页面的信息层级。
- 项目颜色选择器与创建、编辑流程使用同一套交互规则。

### 通知与活动信号

- 任务通知现在携带项目、看板与任务目标信息，可直接打开对应任务详情。
- 为旧通知回填深链数据，并在目标不存在或不可访问时提供安全降级。
- 通知页升级为可连续浏览的信号流，未读状态与时间信息更加清晰。
- 项目活动改为横向时间线，默认定位到最新事件，并使用虚拟渲染保持长列表流畅。

### 报告与知识工作区

- 报告生成加入总超时、有限重试与指数退避，覆盖网络错误、限流、服务端错误和不完整输出。
- 报告生成状态按项目隔离，切换页面后仍能恢复当前生成进度，不会串用其他项目的快照。
- 修复报告 Markdown 渲染，并限制内存中的生成快照数量。
- 优化知识文档创建、编辑、查询和助手调用流程。

### 更新与部署

- updater 在切换代码前建立恢复检查点；容器或宿主机中断后，重启可尝试恢复上一版本。
- 数据库备份前按数据库体量验证空间，备份后默认至少保留 1 GiB 可用空间。
- 更新请求支持幂等重放与状态协调，避免请求已启动但业务端误判为失败。
- 部署完成后同时检查前端、后端健康状态与后端实际版本。
- `scripts/deploy.sh` 可自动探测 PyPI、npm、Debian 与 Alpine 镜像源，并复用 BuildKit 依赖缓存。

### 兼容性说明

- 数据库迁移会自动执行，但不会自动降级；更新失败时数据库备份会保留。
- 旧通知的深链字段由迁移脚本自动回填，不需要手工处理。
- 新增的报告可靠性参数均有默认值，旧部署无需立即配置。

## 升级到 v0.2.2

在仓库根目录执行：

```bash
scripts/update.sh 0.2.2
```

也可以由超级管理员在「系统更新」页阅读 Release 说明并启动更新。生产环境应先确认 `.env` 已设置随机的 `FLOWMIND_UPDATER_TOKEN`，并为 `updater_state` 数据卷预留足够的数据库备份空间。

完整更新流程、失败恢复与镜像源选项见[部署指南](/guide/deployment#版本更新)。
